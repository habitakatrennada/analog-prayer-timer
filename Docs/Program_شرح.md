# شرح `Program.cs` (بسيط للأطفال)

هذا الملف يشرح ما يحدث داخل `Program.cs` خطوة بخطوة وبطريقة بسيطة للأطفال.

## مقدمة سريعة
- هذا البرنامج يقرأ تاريخ اليوم وموقعًا جغرافيًا (خط عرض وخط طول)، ثم يحسب أوقات الصلاة ويعرضها على الشاشة.

## تشغيل البرنامج
افتح الطرفية في مجلد المشروع وشغّل:

```bash
dotnet run
```

سترى رسالة ترحيبية ثم قائمة بأسماء الصلوات وأوقاتها.

## أجزاء `Program.cs` وشرحها بطريقة سهلة

1) جلب الأدوات (using)

```csharp
using AnalogPrayerTimer.PrayerCalculations;
using AnalogPrayerTimer.Models;
```

- هذه الأسطر تُخبر البرنامج أنّه سيستخدم أجزاءً من ملفات أخرى (مثل صناديق أدوات). فكروا بها كصندوق أدوات نستخدمه داخل البرنامج.

2) رسالة ترحيب

```csharp
Console.WriteLine("مرحباً بكم في مشروع Analog Prayer Timer!");
```

- تطبع رسالة على الشاشة لتخبر المستخدم أن البرنامج بدأ.

3) تحديد الموقع

```csharp
var location = new Location { Latitude = 24.7136, Longitude = 46.6753 };
```

- `Location` هو كائن (مثل بطاقة) يحمل معلومات الموقع.
- `Latitude` و `Longitude` هما رقمان يحددان مكانًا على الخريطة.
- جرّبوا تغيير الأرقام وشغّلوا البرنامج مرة أخرى لتروا اختلاف أوقات الصلاة.

4) إنشاء آلة حساب أوقات الصلاة

```csharp
var calculator = new PrayerTimeCalculator();
```

- هذا يصنع شيئًا يمكننا أن نطلب منه حساب أوقات الصلاة. فكروا به كآلة حاسبة صغيرة.

5) الحصول على تاريخ اليوم

```csharp
var today = DateTime.Today;
```

- `DateTime.Today` يعطي تاريخ اليوم الحالي، مثل تاريخ اليوم في التقويم.

6) طلب حساب الأوقات

```csharp
var prayerTimes = calculator.CalculateTimes(today, location);
```

- هنا نطلب من `calculator` أن يحسب أوقات الصلاة للـ `today` والمكان `location`.

7) طباعة النتائج (حلقة `foreach`)

```csharp
foreach (var prayer in prayerTimes)
{
    Console.WriteLine($"{prayer.Name,-10}: {prayer.Time:HH:mm}");
}
```

- `foreach` تعني: "لِكل عنصر في القائمة افعل التالي".
- في كل دورة نأخذ اسم الصلاة (`prayer.Name`) والوقت (`prayer.Time`) ونطبعهما.
- `HH:mm` يهيئ الوقت ليظهر بالساعات والدقائق، مثل `13:45`.

8) تشجيع للتجربة

في نهاية `Program.cs` توجد رسالة تشجع المستخدم على تعديل القيم والتجربة.

## مفردات بسيطة ليفهمها الأطفال

- `Console.WriteLine(...)` : اطبع نص على الشاشة.
- `var` : اطلب من الكمبيوتر أن يختار نوع المتغير تلقائيًا.
- `class` أو `object` : فكروا بها كقوالب أو صناديق يمكن أن نحفظ بداخلها بيانات.
- `foreach` : حلقة تكرر التعليمات على كل عنصر في القائمة.
- `DateTime` : صنف يمثل التاريخ والوقت.

## أنشطة عملية قصيرة للأطفال

1. شغّلوا البرنامج كما في الأعلى.
2. غيّروا `Latitude` إلى رقم آخر (مثلاً 51.5074 لِـ لندن) ثم أعدوا التشغيل، لاحظوا الاختلاف.
3. أضيفوا `Console.WriteLine("اختبار")` قبل الحلقة ولاحظوا ما سيحدث.
